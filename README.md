This project focuses on analysing student enrolment data from South African public universities between 2009 and 2016.

The purpose of the analysis is to explore enrolment patterns, understand changes in student headcounts and Full-Time Equivalent (FTE) enrolments, and identify trends across different universities over time.

Using MySQL for data extraction and analysis and Power BI for data visualisation, this project transforms raw enrolment data into meaningful insights that can support data-driven decision-making.

## Project Objectives

The main objectives of this project are to:

- Analyse student enrolment trends across South African public universities.
- Examine undergraduate and postgraduate enrolment patterns.
- Compare student headcounts across different institutions.
- Investigate changes in enrolment figures between 2009 and 2016.
- Analyse Full-Time Equivalent (FTE) enrolments.
- Present key findings through interactive Power BI visualisations.
